# AI Auto Video Bot

Automatic Hindi horror Shorts generator.

This project can:
- Create a Hindi horror story with AI
- Generate scene images
- Generate Hindi narration
- Create a vertical 9:16 video
- Add subtitles
- Create a thumbnail
- Upload the finished video to YouTube

## Setup

Required GitHub Secrets:

- OPENAI_API_KEY
- YOUTUBE_CLIENT_ID
- YOUTUBE_CLIENT_SECRET
- YOUTUBE_REFRESH_TOKEN

The bot can run automatically using GitHub Actions.

Never put API keys or passwords directly inside the code.
